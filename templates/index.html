Connect to this lab with Remote Desktop

This lab is a Windows desktop. You reach it with RDP, the Remote Desktop Protocol. Your computer shows the Windows desktop in a window, and you work in it as if the machine were in front of you.

Address -
User name -
Password The password your instructor gave you for this lab.
You must be on the course VPN first. This address is private. It does not work from the open internet. Start your VPN client, then connect.

The quickest way on any system: select open .rdp in the Connect column. Your computer downloads a small file. Open that file. The address and the user name are already in it, so you only type the password.

Windows

Windows includes the client. You do not install anything.

  1. Select copy address in the Connect column.
  2. Press the Windows key, type Remote Desktop Connection, and open it.
  3. Paste the address into the Computer box. Paste it. Do not type it. One wrong digit gives the error “Remote Desktop can’t connect to the remote computer”, which does not tell you that the address is wrong.
  4. Select Connect.
  5. Give the user name above and your lab password.
  6. A certificate warning appears. The lab uses a self-signed certificate, so this is expected. Select Yes.
macOS
  1. Install Windows App from the Mac App Store. Apple renamed it; older guides call it Microsoft Remote Desktop.
  2. Open it and select +, then Add PC.
  3. Put the address above in PC name.
  4. Leave User account set to Ask when required, or add the user name above.
  5. Save, then double-click the entry.
  6. Accept the certificate warning. It is expected.
Linux

Install one client, then connect.

# Debian or Ubuntu
sudo apt install freerdp2-x11

# Fedora
sudo dnf install freerdp

# then connect, with your own user name and address
xfreerdp /u:USER /v:ADDRESS /dynamic-resolution +clipboard

FreeRDP asks for the password. It also asks about the certificate the first time; answer Y. If your distribution ships FreeRDP 3, the command is xfreerdp3. Remmina is a graphical alternative, and it is in every major repository.

Useful to know
  • Save your work off the VM. The lab is deleted when the timer ends. The .rdp file shares your local drives, so you can copy files out through \\tsclient\.
  • Extend adds time when less than an hour remains.
  • A black screen for a few seconds after you log in is normal. The desktop is still starting.
  • If the connection is refused, check the VPN first, then check that the address matches the Connect column exactly.
